# Backup File (Export and Restore) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user save everything they have made in the app as one `.nmbackup` file, and restore from it by merging, without ever deleting anything on the phone.

**Architecture:** All rules live in `NorseMixologyCore` and are tested with `swift test`:
- **Format:** a versioned `BackupManifest` (JSON).
- **Archive:** `BackupArchive`, AppleArchive with LZFSE.
- **Writer:** `BackupWriter` stages the manifest and photo files and packs them, off the main actor, with its own `ModelContext`s.
- **Reader:** `BackupReader` unpacks and validates, refusing bad files before anything touches the store.
- **Merger:** `BackupMerger` fills gaps, saves once and rolls back on failure.
- **View model:** `BackupViewModel` is `@MainActor @Observable` and sits at the app root.

The app adds a Settings section, a root-level presenter (share sheet, restore summary, errors, `.onOpenURL`) and the exported `.nmbackup` document type.

**Tech Stack:** Swift 5.9, SwiftUI (iOS 17), SwiftData, AppleArchive + System (FilePath), UniformTypeIdentifiers, XCTest, xcodegen.

**Spec:** `docs/superpowers/specs/2026-10-13-backup-design.md`

## Global Constraints

- **Platform:** min iOS **17.0**, iOS only. Do not touch `android/`. No new dependencies; AppleArchive, System and UniformTypeIdentifiers are system frameworks.
- **File format:**
  - The file extension is **`.nmbackup`**. The exported UTType is **`dev.martinloeseth.norsemixology.backup`**, conforming to `public.data` and `public.archive`.
  - The file name is **`Norse Mixology Backup YYYY-MM-DD.nmbackup`**.
  - The archive holds `manifest.json` plus `photos/<photoId>.jpg` and `photos/<photoId>-thumb.jpg`.
  - The manifest's `formatVersion` is **1**. Dates are ISO-8601 with milliseconds. Unknown keys are ignored.
- **Restore never deletes anything on the phone:**
  - **Cabinet:** skip a record whose `ingredientStyleId` the phone already has.
  - **Shopping:** skip a record whose `ingredientStyleId` is already on the list, or in the cabinet after the merge.
  - **Favourites:** skip a record whose `recipeId` the phone already has.
  - **Takes:** the newer `updatedAt` wins. Photos with an id the phone already has are skipped. New photos are added oldest first up to **6 per recipe**; the rest count as skipped. Never create an empty take.
- **Restore is all-or-nothing:** one `save()`. On any failure it does `rollback()` and throws `BackupError.restoreFailed` (or `.outOfSpace`). Restoring the same file twice changes nothing.
- **Bad files are refused before the store is touched.** `BackupError` cases: `notABackup`, `newerVersion`, `damaged`, `outOfSpace`, `exportFailed`, `restoreFailed`. Photo paths must start with `photos/` and contain no `..`, and must not be absolute or resolve outside the unpacked folder. Ratings must be 0…5. Notes are trimmed to 2,000 characters.
- **Temporary files:** every temporary folder starts with **`NorseMixologyBackup-`** and is always removed. Leftovers are removed at launch.
- **Device backup:** the SwiftData store must not be excluded from device backup (`StoreBackupCheck` at launch).
- **Exact user-facing strings:**
  - Footer: "Your iPhone's own iCloud backup also includes this app's data. Use this to keep a copy you control or to move to a new phone."
  - Summary line: "Nothing on this phone will be deleted."
  - Errors: "This file isn't a Norse Mixology backup." / "This backup was made by a newer version of the app. Update the app to restore it." / "This backup is damaged and can't be restored." / "There isn't enough free space. Free some space and try again." / "Couldn't create the backup. Try again." / "Couldn't restore. Nothing was changed."
- **Code conventions:**
  - `@Observable` only; no Combine or `ObservableObject`.
  - Design tokens only (`DesignTokens`, `.dsText`, `.dsPrimary`).
  - 44 pt targets.
  - Structured logging via `AppLog.backup`, never logging note contents; no `print`.
- **Strings and project files:**
  - New UI strings end up in `ios/NorseMixology/Localizable.xcstrings` via `ios/scripts/sync-strings.sh`.
  - New app files are registered with `xcodegen generate`. Verify each appears in a `SwiftCompile` line of the build log.

**Commands:**
- Core tests: `cd ios/Packages/NorseMixologyCore && swift test`. Baseline on this branch is **289 tests, 0 failures**; confirm before Task 1. Filter with `--filter <TestClass>`.
- App build, always by destination id: `cd ios && xcodebuild -project NorseMixology.xcodeproj -scheme NorseMixology -destination 'id=107DA7C9-B4F6-4568-8F08-DFB149A4F204' build`

## Review Focus

These five conditions are the most likely to bite someone, and the spec only implies them:

1. **A note typed seconds before "Back up now"** (still in the 0.6 s autosave window) must be in the backup. The view model saves the main context first. Pinned by `BackupViewModelTests.testAnUnsavedEditIsIncludedInTheBackup` (Task 4).
2. **Opening a second backup while a summary is open**, or tapping Restore twice, must replace or ignore cleanly and leave no temporary folders behind. Pinned by `testOpeningASecondFileReplacesTheFirstAndCleansUp` and `testRestoreOnlyRunsFromAnOpenedBackup` (Task 4).
3. **A malicious or broken file** (path traversal, `formatVersion: 2`, a zero-byte photo, an empty file) must be refused with the right message, leaving nothing behind. Pinned by `BackupReaderTests` (Task 2) and `testAnythingThatIsNotAnArchiveIsRefused` (Task 1).
4. **Tapping a `.nmbackup` in Files or AirDrop while the app is on another tab or closed** must open the restore summary. This is a simulator check in Task 5.
5. **A backup stored in iCloud Drive that isn't downloaded yet** must be downloaded before reading. `BackupViewModel.withReadableFile` uses `NSFileCoordinator` and security-scoped access. Unit tests can't exercise this; it is code-reviewed in Task 4 and a simulator check (picking from iCloud Drive) in Task 5.

```swift
import Foundation
import SwiftData
@testable import NorseMixologyCore

/// On-disk stores and hand-made archives for the backup tests. On-disk (not
/// in-memory) because the writer reads through its own `ModelContext`s.
final class BackupTestStore {
    let directory: URL
    let container: ModelContainer

    static let schema = Schema([CabinetItem.self, FavouriteRecipe.self, ShoppingItem.self, RecipeTake.self, RecipePhoto.self])

    init() throws {
        directory = FileManager.default.temporaryDirectory.appendingPathComponent("BackupTests-\(UUID().uuidString)", isDirectory: true)
        try FileManager.default.createDirectory(at: directory, withIntermediateDirectories: true)
        let configuration = ModelConfiguration(schema: Self.schema, url: directory.appendingPathComponent("store.sqlite"))
        container = try ModelContainer(for: Self.schema, configurations: [configuration])
    }

    deinit {
        try? FileManager.default.removeItem(at: directory)
    }

    /// A scratch folder inside this store's directory, removed with it.
    func scratch(_ name: String = UUID().uuidString) throws -> URL {
        let url = directory.appendingPathComponent(name, isDirectory: true)
        try FileManager.default.createDirectory(at: url, withIntermediateDirectories: true)
        return url
    }
}

enum BackupFixtures {
    static let flavor = FlavorProfile(sweetness: 0.1, bitterness: 0.8, smokiness: 0, citrus: 0.2, floral: 0, spice: 0.1,
                                      herbal: 0.6, fruity: 0, oaky: 0, abv: 25)
    /// Whole seconds, so dates survive the millisecond JSON format exactly.
    static func date(_ seconds: TimeInterval) -> Date { Date(timeIntervalSince1970: 1_760_000_000 + seconds) }

    static func cabinetItem(styleId: UUID = UUID(), name: String = "Campari", brand: String? = nil) -> CabinetItem {
        CabinetItem(ingredientStyleId: styleId, ingredientFamilyId: UUID(), categoryId: UUID(), displayName: name, brand: brand,
                    style: name, family: "Bitter Aperitif", category: "Liqueur", flavorProfile: flavor, dateAdded: date(1))
    }

    /// Fills a store with one of everything, two photos on one recipe.
    @discardableResult
    static func populate(_ context: ModelContext) throws -> (recipeId: UUID, photoIds: [UUID]) {
        let recipeId = UUID()
        context.insert(cabinetItem(name: "Campari", brand: "Campari"))
        context.insert(cabinetItem(name: "Gin"))
        context.insert(FavouriteRecipe(recipeId: recipeId, recipeName: "Negroni", dateFavourited: date(2)))
        context.insert(ShoppingItem(ingredientStyleId: UUID(), styleName: "Sweet Vermouth", dateAdded: date(3)))
        context.insert(RecipeTake(recipeId: recipeId, recipeName: "Negroni", rating: 5, notes: "Orange peel.", updatedAt: date(4)))
        let first = RecipePhoto(recipeId: recipeId, thumbnail: Data([1, 2]), full: Data(repeating: 7, count: 4_000), dateAdded: date(5))
        let second = RecipePhoto(recipeId: recipeId, thumbnail: Data([3, 4]), full: Data(repeating: 9, count: 5_000), dateAdded: date(6))
        context.insert(first)
        context.insert(second)
        try context.save()
        return (recipeId, [first.id, second.id])
    }

    /// Packs a hand-made folder (`manifest.json` plus files) into an archive.
    static func archive(manifest: Data?, files: [String: Data] = [:], in folder: URL) throws -> URL {
        let staging = folder.appendingPathComponent("staging-\(UUID().uuidString)", isDirectory: true)
        try FileManager.default.createDirectory(at: staging.appendingPathComponent("photos"), withIntermediateDirectories: true)
        if let manifest { try manifest.write(to: staging.appendingPathComponent(BackupManifest.fileName)) }
        for (path, data) in files { try data.write(to: staging.appendingPathComponent(path)) }
        let archive = folder.appendingPathComponent("hand-made-\(UUID().uuidString).nmbackup")
        try BackupArchive.pack(directory: staging, into: archive)
        return archive
    }

    /// A valid manifest with one take and one photo, plus the photo files it names.
    static func validManifest(photoId: UUID = UUID(), recipeId: UUID = UUID(), rating: Int = 4, notes: String = "Nice")
        -> (manifest: BackupManifest, files: [String: Data]) {
        let paths = PhotoRecord.paths(for: photoId)
        let manifest = BackupManifest(
            appVersion: "1.0", createdAt: date(100),
            takes: [TakeRecord(id: UUID(), recipeId: recipeId, recipeName: "Daiquiri", rating: rating, notes: notes, updatedAt: date(10))],
            photos: [PhotoRecord(id: photoId, recipeId: recipeId, dateAdded: date(11), fullFile: paths.full, thumbnailFile: paths.thumbnail)])
        return (manifest, [paths.full: Data(repeating: 5, count: 900), paths.thumbnail: Data([8, 8])])
    }

    static func encoded(_ manifest: BackupManifest) throws -> Data { try BackupJSON.encoder().encode(manifest) }
}
```

```swift
@testable import NorseMixologyCore

/// Backup spec §2: every stored field survives model → record → JSON → record → model.
final class BackupManifestTests: XCTestCase {
    func testRecordsCarryEveryModelField() {
        let item = BackupFixtures.cabinetItem(name: "Campari", brand: "Campari")
        let back = CabinetRecord(item).makeModel()
        XCTAssertEqual(back.id, item.id)
        XCTAssertEqual(back.ingredientStyleId, item.ingredientStyleId)
        XCTAssertEqual(back.ingredientFamilyId, item.ingredientFamilyId)
        XCTAssertEqual(back.categoryId, item.categoryId)
        XCTAssertEqual(back.displayName, "Campari")
        XCTAssertEqual(back.brand, "Campari")
        XCTAssertEqual(back.style, item.style)
        XCTAssertEqual(back.family, item.family)
        XCTAssertEqual(back.category, item.category)
        XCTAssertEqual(back.flavorProfile, BackupFixtures.flavor)
        XCTAssertEqual(back.dateAdded, item.dateAdded)

        let favourite = FavouriteRecipe(recipeId: UUID(), recipeName: "Negroni", dateFavourited: BackupFixtures.date(2))
        XCTAssertEqual(FavouriteRecord(FavouriteRecord(favourite).makeModel()), FavouriteRecord(favourite))
        let shopping = ShoppingItem(ingredientStyleId: UUID(), styleName: "Vermouth", dateAdded: BackupFixtures.date(3))
        XCTAssertEqual(ShoppingRecord(ShoppingRecord(shopping).makeModel()), ShoppingRecord(shopping))
        let take = RecipeTake(recipeId: UUID(), recipeName: "Negroni", rating: 3, notes: "Hm.", updatedAt: BackupFixtures.date(4))
        XCTAssertEqual(TakeRecord(TakeRecord(take).makeModel()), TakeRecord(take))
    }

    func testManifestSurvivesJSONIncludingMilliseconds() throws {
        let precise = Date(timeIntervalSince1970: 1_760_000_000.5)
        let manifest = BackupManifest(
            appVersion: "1.0", createdAt: precise,
            cabinet: [CabinetRecord(BackupFixtures.cabinetItem())],
            favourites: [FavouriteRecord(id: UUID(), recipeId: UUID(), recipeName: "Negroni", dateFavourited: BackupFixtures.date(1))],
            shopping: [ShoppingRecord(id: UUID(), ingredientStyleId: UUID(), styleName: "Gin", dateAdded: BackupFixtures.date(2))],
            takes: [TakeRecord(id: UUID(), recipeId: UUID(), recipeName: "Negroni", rating: 5, notes: "Yes", updatedAt: BackupFixtures.date(3))],
            photos: [PhotoRecord(id: UUID(), recipeId: UUID(), dateAdded: BackupFixtures.date(4), fullFile: "photos/a.jpg", thumbnailFile: "photos/a-thumb.jpg")])

        let data = try BackupJSON.encoder().encode(manifest)
        let decoded = try BackupJSON.decoder().decode(BackupManifest.self, from: data)

        XCTAssertEqual(decoded, manifest)
        XCTAssertTrue(String(decoding: data, as: UTF8.self).contains("\"formatVersion\" : 1"))
    }

    func testUnknownKeysAreIgnored() throws {
        var object = try JSONSerialization.jsonObject(with: BackupFixtures.encoded(BackupManifest(appVersion: "1.0", createdAt: BackupFixtures.date(0)))) as! [String: Any]
        object["somethingNew"] = ["a": 1]
        let data = try JSONSerialization.data(withJSONObject: object)

        XCTAssertEqual(try BackupJSON.decoder().decode(BackupManifest.self, from: data).appVersion, "1.0")
    }

    func testErrorsMapToWhatTheUserSees() {
        XCTAssertEqual(BackupError.from(BackupError.damaged, otherwise: .exportFailed), .damaged)
        XCTAssertEqual(BackupError.from(NSError(domain: NSPOSIXErrorDomain, code: Int(ENOSPC)), otherwise: .exportFailed), .outOfSpace)
        XCTAssertEqual(BackupError.from(CocoaError(.fileWriteOutOfSpace), otherwise: .exportFailed), .outOfSpace)
        let wrapped = NSError(domain: "x", code: 1, userInfo: [NSUnderlyingErrorKey: NSError(domain: NSPOSIXErrorDomain, code: Int(ENOSPC))])
        XCTAssertEqual(BackupError.from(wrapped, otherwise: .restoreFailed), .outOfSpace)
        XCTAssertEqual(BackupError.from(CocoaError(.fileReadNoPermission), otherwise: .restoreFailed), .restoreFailed)
    }
}
```

```swift
import XCTest
import SwiftData
@testable import NorseMixologyCore

/// Backup spec §3/§5: the archive format, the writer, temporary-file clean-up
/// and the device-backup check.
final class BackupWriterTests: XCTestCase {
    func testArchivePacksAndUnpacksAFolder() throws {
        let store = try BackupTestStore()
        let archive = try BackupFixtures.archive(manifest: Data("{}".utf8), files: ["photos/a.jpg": Data(repeating: 1, count: 3_000)],
                                                 in: try store.scratch())
        let target = try store.scratch()

        try BackupArchive.unpack(archive, into: target)

        XCTAssertEqual(try Data(contentsOf: target.appendingPathComponent("manifest.json")), Data("{}".utf8))
        XCTAssertEqual(try Data(contentsOf: target.appendingPathComponent("photos/a.jpg")).count, 3_000)
    }

    func testAnythingThatIsNotAnArchiveIsRefused() throws {
        let store = try BackupTestStore()
        let folder = try store.scratch()
        let junk = folder.appendingPathComponent("junk.nmbackup")
        try Data("hello".utf8).write(to: junk)
        let empty = folder.appendingPathComponent("empty.nmbackup")
        try Data().write(to: empty)

        for file in [junk, empty, folder.appendingPathComponent("missing.nmbackup")] {
            XCTAssertThrowsError(try BackupArchive.unpack(file, into: try store.scratch())) { error in
                XCTAssertEqual(error as? BackupError, .notABackup, file.lastPathComponent)
            }
        }
    }

    func testTheWriterStoresEverythingWithPhotosAsFiles() throws {
        let store = try BackupTestStore()
        let (_, photoIds) = try BackupFixtures.populate(ModelContext(store.container))
        let now = ISO8601DateFormatter().date(from: "2026-10-17T12:00:00Z")!

        let archive = try BackupWriter.write(container: store.container, appVersion: "1.0", now: now, temporaryDirectory: try store.scratch())

        XCTAssertEqual(archive.lastPathComponent, "Norse Mixology Backup 2026-10-17.nmbackup")
        let unpacked = try store.scratch()
        try BackupArchive.unpack(archive, into: unpacked)
        let manifest = try BackupJSON.decoder().decode(BackupManifest.self, from: Data(contentsOf: unpacked.appendingPathComponent("manifest.json")))
        XCTAssertEqual(manifest.formatVersion, 1)
        XCTAssertEqual(manifest.appVersion, "1.0")
        XCTAssertEqual(manifest.createdAt, now)
        XCTAssertEqual(manifest.cabinet.count, 2)
        XCTAssertEqual(manifest.favourites.count, 1)
        XCTAssertEqual(manifest.shopping.count, 1)
        XCTAssertEqual(manifest.takes.map(\.notes), ["Orange peel."])
        XCTAssertEqual(manifest.photos.map(\.id), photoIds, "oldest first")
        let first = manifest.photos[0]
        XCTAssertEqual(try Data(contentsOf: unpacked.appendingPathComponent(first.fullFile)), Data(repeating: 7, count: 4_000))
        XCTAssertEqual(try Data(contentsOf: unpacked.appendingPathComponent(first.thumbnailFile)), Data([1, 2]))
    }

    func testAnEmptyStoreGivesAValidBackupWithNothingInIt() throws {
        let store = try BackupTestStore()

        let archive = try BackupWriter.write(container: store.container, appVersion: "1.0", temporaryDirectory: try store.scratch())

        let opened = try BackupReader.open(archive, temporaryDirectory: try store.scratch())
        defer { opened.close() }
        XCTAssertEqual(opened.summary.cabinetItems + opened.summary.favourites + opened.summary.shoppingItems

    }

    func testOnlyTheArchiveIsLeftBehind() throws {
        let store = try BackupTestStore()
        try BackupFixtures.populate(ModelContext(store.container))
        let temporary = try store.scratch()

        let archive = try BackupWriter.write(container: store.container, appVersion: "1.0", temporaryDirectory: temporary)

        let workspace = archive.deletingLastPathComponent()
        XCTAssertTrue(workspace.lastPathComponent.hasPrefix(BackupWriter.temporaryPrefix))
        XCTAssertEqual(try FileManager.default.contentsOfDirectory(atPath: workspace.path), [archive.lastPathComponent])
    }

    func testStaleTemporaryFilesAreCleanedUp() throws {
        let store = try BackupTestStore()
        let temporary = try store.scratch()
        let stale = temporary.appendingPathComponent(BackupWriter.temporaryPrefix + "old", isDirectory: true)
        try FileManager.default.createDirectory(at: stale, withIntermediateDirectories: true)

        BackupWriter.cleanUpStaleFiles(in: temporary)

        XCTAssertFalse(FileManager.default.fileExists(atPath: stale.path))
        XCTAssertTrue(FileManager.default.fileExists(atPath: unrelated.path))
    }

    func testTheStoreIsPutBackIntoDeviceBackups() throws {
        let store = try BackupTestStore()
        var file = try store.scratch().appendingPathComponent("store.sqlite")
        try Data("db".utf8).write(to: file)

        excluded.isExcludedFromBackup = true
        try file.setResourceValues(excluded)

        XCTAssertTrue(StoreBackupCheck.ensureIncluded(file))
        file.removeAllCachedResourceValues()
        XCTAssertEqual(try file.resourceValues(forKeys: [.isExcludedFromBackupKey]).isExcludedFromBackup, false)
        XCTAssertFalse(StoreBackupCheck.ensureIncluded(file), "nothing to fix the second time")
    }
```

```swift
import Foundation

/// The contents of `manifest.json` inside a `.nmbackup` file (Backup spec §2).
/// Ids are kept as they are, so a restore can recognise what it already has.
/// Unknown keys are ignored when decoding, so additive fields stay readable.
public struct BackupManifest: Codable, Equatable, Sendable {
    public static let currentFormatVersion = 1
    public static let fileName = "manifest.json"

    public var formatVersion: Int
    public var appVersion: String
    public var createdAt: Date
    public var cabinet: [CabinetRecord]
    public var favourites: [FavouriteRecord]
    public var shopping: [ShoppingRecord]
    public var takes: [TakeRecord]
    public var photos: [PhotoRecord]

    public init(formatVersion: Int = BackupManifest.currentFormatVersion, appVersion: String, createdAt: Date,

/// JSON coding for the manifest: ISO-8601 dates with milliseconds, stable key order.
enum BackupJSON {
    static func encoder() -> JSONEncoder {
        let encoder = JSONEncoder()
        encoder.outputFormatting = [.prettyPrinted, .sortedKeys]
        encoder.dateEncodingStrategy = .custom { date, encoder in
            var container = encoder.singleValueContainer()
            try container.encode(formatter().string(from: date))
        }
        return encoder
    }

    static func decoder() -> JSONDecoder {
        let decoder = JSONDecoder()
        decoder.dateDecodingStrategy = .custom { decoder in
            let container = try decoder.singleValueContainer()
            let text = try container.decode(String.self)
            guard let date = formatter().date(from: text) else {
                throw DecodingError.dataCorruptedError(in: container, debugDescription: "Not an ISO-8601 date: \(text)")
            }
            return date
        }
        return decoder
    }

    private static func formatter() -> ISO8601DateFormatter {
        let formatter = ISO8601DateFormatter()
        formatter.formatOptions = [.withInternetDateTime, .withFractionalSeconds]
        return formatter
    }
```

```swift
import Foundation

/// Everything that can go wrong with a backup, as the user sees it (Backup spec §3–4).
public enum BackupError: Error, Equatable, Sendable {
    /// Not an archive, empty, or an archive without a manifest.
    case notABackup
    /// Made by a newer version of the app (`formatVersion` too high).
    case newerVersion
    /// An archive with a broken manifest, a missing or unsafe photo path, or invalid values.
    case damaged
    case outOfSpace
    /// Writing the backup failed for a reason other than space.
    case exportFailed
    /// The restore could not be saved; it was rolled back, so nothing changed.
    case restoreFailed

    /// Maps any error to a `BackupError`: backup errors pass through, a full disk
    /// becomes `.outOfSpace`, anything else becomes `fallback`.
    public static func from(_ error: Error, otherwise fallback: BackupError) -> BackupError {
        if let backupError = error as? BackupError { return backupError }
        let nsError = error as NSError
        if nsError.domain == NSPOSIXErrorDomain && nsError.code == Int(ENOSPC) { return .outOfSpace }
        if nsError.domain == NSCocoaErrorDomain && nsError.code == NSFileWriteOutOfSpaceError { return .outOfSpace }
        if let underlying = nsError.userInfo[NSUnderlyingErrorKey] as? NSError {
            return from(underlying, otherwise: fallback)
        }
        return fallback
    }
}
```

```swift
import Foundation
import AppleArchive
import System

/// Packs a folder into one AppleArchive file (LZFSE) and unpacks it again.
/// iOS has no public zip API; AppleArchive is built in (iOS 14+, macOS 11+).
enum BackupArchive {
    static func pack(directory: URL, into file: URL) throws {
        guard let fileStream = ArchiveByteStream.fileStream(
            path: FilePath(file.path), mode: .writeOnly, options: [.create, .truncate],
            permissions: FilePermissions(rawValue: 0o644)) else { throw BackupError.exportFailed }
        defer { try? fileStream.close() }
        guard let compressStream = ArchiveByteStream.compressionStream(using: .lzfse, writingTo: fileStream) else {
            throw BackupError.exportFailed
        }
        defer { try? compressStream.close() }
        guard let encodeStream = ArchiveStream.encodeStream(writingTo: compressStream) else { throw BackupError.exportFailed }
        defer { try? encodeStream.close() }
        guard let keys = ArchiveHeader.FieldKeySet("TYP,PAT,DAT,MOD") else { throw BackupError.exportFailed }
        try encodeStream.writeDirectoryContents(archiveFrom: FilePath(directory.path), keySet: keys)
    }

    /// Throws `.notABackup` for anything that is not a readable archive.
    static func unpack(_ file: URL, into directory: URL) throws {
        // An empty file decodes as an empty archive; it is still not a backup.
        let size = (try? file.resourceValues(forKeys: [.fileSizeKey]).fileSize) ?? 0
        guard size > 0 else { throw BackupError.notABackup }
        guard let fileStream = ArchiveByteStream.fileStream(
            path: FilePath(file.path), mode: .readOnly, options: [],
            permissions: FilePermissions(rawValue: 0o644)) else { throw BackupError.notABackup }
        defer { try? fileStream.close() }
        guard let decompressStream = ArchiveByteStream.decompressionStream(readingFrom: fileStream) else {
            throw BackupError.notABackup
        }
        defer { try? decompressStream.close() }
        guard let decodeStream = ArchiveStream.decodeStream(readingFrom: decompressStream) else { throw BackupError.notABackup }
        defer { try? decodeStream.close() }
        guard let extractStream = ArchiveStream.extractStream(
            extractingTo: FilePath(directory.path), flags: [.ignoreOperationNotPermitted]) else { throw BackupError.notABackup }
        defer { try? extractStream.close() }
        do {
            _ = try ArchiveStream.process(readingFrom: decodeStream, writingTo: extractStream)
        } catch {
            throw BackupError.notABackup
        }
    }
}
```

`Backup/BackupWriter.swift`:

```swift
import Foundation
import SwiftData

/// Writes everything the user has made into one `.nmbackup` file (Backup spec §3).
///
/// Call off the main actor. It reads through its own `ModelContext`s, so it sees
/// saved data only — callers save the main context first. Photos are written one
/// at a time, each read through a short-lived context, so a large library is
/// never held in memory at once.
public enum BackupWriter {
    /// Every temporary folder the backup code creates starts with this, so
    /// `cleanUpStaleFiles` can remove leftovers after a crash or kill.
    public static let temporaryPrefix = "NorseMixologyBackup-"

    public static func write(container: ModelContainer, appVersion: String, now: Date = Date(),
                             temporaryDirectory: URL = FileManager.default.temporaryDirectory) throws -> URL {
        let fileManager = FileManager.default
        let workspace = temporaryDirectory.appendingPathComponent(temporaryPrefix + UUID().uuidString, isDirectory: true)
        let staging = workspace.appendingPathComponent("staging", isDirectory: true)
        do {
            try fileManager.createDirectory(at: staging.appendingPathComponent("photos", isDirectory: true),
                                            withIntermediateDirectories: true)
            try stage(container: container, appVersion: appVersion, now: now, into: staging)
            let archive = workspace.appendingPathComponent(fileName(for: now))
            try BackupArchive.pack(directory: staging, into: archive)
            try? fileManager.removeItem(at: staging)
            return archive
        } catch {
            try? fileManager.removeItem(at: workspace)
            AppLog.backup.error("Backup failed: \(String(describing: error), privacy: .public)")
            throw BackupError.from(error, otherwise: .exportFailed)
        }
    }

    /// `Norse Mixology Backup 2026-10-17.nmbackup`, in the device's time zone.
    public static func fileName(for date: Date) -> String {
        let formatter = DateFormatter()
        formatter.calendar = Calendar(identifier: .gregorian)
        formatter.locale = Locale(identifier: "en_US_POSIX")
        formatter.dateFormat = "yyyy-MM-dd"
        return "Norse Mixology Backup \(formatter.string(from: date)).nmbackup"
    }

    /// Removes leftover backup folders from an earlier run (called at launch).
    public static func cleanUpStaleFiles(in temporaryDirectory: URL = FileManager.default.temporaryDirectory) {
        let fileManager = FileManager.default
        guard let items = try? fileManager.contentsOfDirectory(at: temporaryDirectory, includingPropertiesForKeys: nil) else {
            return
        }
        for item in items where item.lastPathComponent.hasPrefix(temporaryPrefix) {
            try? fileManager.removeItem(at: item)
        }
    }

    @discardableResult
    static func stage(container: ModelContainer, appVersion: String, now: Date, into folder: URL) throws -> BackupManifest {
        let context = ModelContext(container)
        let cabinet = try context.fetch(FetchDescriptor<CabinetItem>()).map(CabinetRecord.init)
        let favourites = try context.fetch(FetchDescriptor<FavouriteRecipe>()).map(FavouriteRecord.init)
        let shopping = try context.fetch(FetchDescriptor<ShoppingItem>()).map(ShoppingRecord.init)
        let takes = try context.fetch(FetchDescriptor<RecipeTake>()).map(TakeRecord.init)

        var headerDescriptor = FetchDescriptor<RecipePhoto>(sortBy: [SortDescriptor(\.dateAdded)])
        headerDescriptor.propertiesToFetch = [\.id, \.recipeId, \.dateAdded]
        let headers = try context.fetch(headerDescriptor).map { (id: $0.id, recipeId: $0.recipeId, dateAdded: $0.dateAdded) }

        var photos: [PhotoRecord] = []
        for header in headers {
            try autoreleasepool {
                let photoContext = ModelContext(container)
                guard let photo = RecipeTakeService.photo(id: header.id, context: photoContext) else { return }
                let paths = PhotoRecord.paths(for: header.id)
                try photo.full.write(to: folder.appendingPathComponent(paths.full))
                try photo.thumbnail.write(to: folder.appendingPathComponent(paths.thumbnail))
                photos.append(PhotoRecord(id: header.id, recipeId: header.recipeId, dateAdded: header.dateAdded,
                                          fullFile: paths.full, thumbnailFile: paths.thumbnail))
            }
        }

        let manifest = BackupManifest(appVersion: appVersion, createdAt: now, cabinet: cabinet, favourites: favourites,
                                      shopping: shopping, takes: takes, photos: photos)
        try BackupJSON.encoder().encode(manifest).write(to: folder.appendingPathComponent(BackupManifest.fileName))
        return manifest
    }
}
```

```swift
import Foundation

/// What a backup contains, shown before the user confirms a restore.
public struct BackupSummary: Equatable, Sendable {
    public var createdAt: Date
    public var cabinetItems: Int
    public var favourites: Int
    public var shoppingItems: Int
    public var takes: Int
    public var photos: Int
}

/// A backup unpacked into a temporary folder and fully validated. `close()` removes the folder.
public struct OpenedBackup: Sendable {
    public let manifest: BackupManifest
    let folder: URL
    let workspace: URL

    public var summary: BackupSummary {
        BackupSummary(createdAt: manifest.createdAt, cabinetItems: manifest.cabinet.count, favourites: manifest.favourites.count,
                      shoppingItems: manifest.shopping.count, takes: manifest.takes.count, photos: manifest.photos.count)
    }

    func url(for relativePath: String) -> URL {
        folder.appendingPathComponent(relativePath)
    }

    public func close() {
        try? FileManager.default.removeItem(at: workspace)
    }
}

/// Opens a `.nmbackup` file and refuses anything that could hurt the store
/// (Backup spec §3, §5). All checks happen before a restore touches the store.
public enum BackupReader {
    public static func open(_ file: URL,
                            temporaryDirectory: URL = FileManager.default.temporaryDirectory) throws -> OpenedBackup {
        let fileManager = FileManager.default
        let workspace = temporaryDirectory.appendingPathComponent(BackupWriter.temporaryPrefix + UUID().uuidString,
                                                                  isDirectory: true)
        let folder = workspace.appendingPathComponent("contents", isDirectory: true)
        do {
            try fileManager.createDirectory(at: folder, withIntermediateDirectories: true)
            try BackupArchive.unpack(file, into: folder)
            var manifest = try readManifest(in: folder)
            try validate(&manifest, in: folder)
            return OpenedBackup(manifest: manifest, folder: folder, workspace: workspace)
        } catch {
            try? fileManager.removeItem(at: workspace)
            let mapped = BackupError.from(error, otherwise: .damaged)
            AppLog.backup.error("Backup refused: \(String(describing: mapped), privacy: .public)")
            throw mapped
        }
    }

    private struct VersionProbe: Decodable {
        let formatVersion: Int
    }

    static func readManifest(in folder: URL) throws -> BackupManifest {
        guard let data = try? Data(contentsOf: folder.appendingPathComponent(BackupManifest.fileName)) else {
            throw BackupError.notABackup
        }
        // Read the version on its own first, so a newer file is reported as newer even if its shape changed.
        guard let probe = try? JSONDecoder().decode(VersionProbe.self, from: data) else { throw BackupError.damaged }
        guard probe.formatVersion <= BackupManifest.currentFormatVersion else { throw BackupError.newerVersion }
        guard probe.formatVersion >= 1,
              let manifest = try? BackupJSON.decoder().decode(BackupManifest.self, from: data) else {
            throw BackupError.damaged
        }
        return manifest
    }

    static func validate(_ manifest: inout BackupManifest, in folder: URL) throws {
        for index in manifest.takes.indices {
            guard TakeLimits.ratingRange.contains(manifest.takes[index].rating) else { throw BackupError.damaged }
            manifest.takes[index].notes = String(manifest.takes[index].notes.prefix(TakeLimits.maxNotesLength))
        }
        let root = folder.resolvingSymlinksInPath().standardizedFileURL.path + "/"
        for photo in manifest.photos {
            for path in [photo.fullFile, photo.thumbnailFile] {
                guard isSafe(path) else { throw BackupError.damaged }
                let resolved = folder.appendingPathComponent(path).resolvingSymlinksInPath().standardizedFileURL
                guard resolved.path.hasPrefix(root) else { throw BackupError.damaged }
                let values = try? resolved.resourceValues(forKeys: [.fileSizeKey, .isRegularFileKey])
                guard values?.isRegularFile == true, (values?.fileSize ?? 0) > 0 else { throw BackupError.damaged }
            }
        }
    }

    /// Only plain relative paths under `photos/`: no absolute paths, no `..`.
    static func isSafe(_ path: String) -> Bool {
        !path.hasPrefix("/") && path.hasPrefix("photos/") && !path.split(separator: "/").contains("..")
    }
}
```

```swift
import Foundation
import SwiftData

/// What a restore changed (Backup spec §3).
public struct RestoreResult: Equatable, Sendable {
    public var cabinetAdded = 0
    public var favouritesAdded = 0
    public var shoppingAdded = 0
    public var takesAdded = 0
    public var takesUpdated = 0
    public var photosAdded = 0
    public var photosSkippedForLimit = 0

    public init() {}

    /// Nothing was added or changed ("Already up to date"). Skipped photos are not changes.
    public var isEmpty: Bool {
        cabinetAdded + favouritesAdded + shoppingAdded + takesAdded + takesUpdated + photosAdded == 0
    }
}

/// Merges an opened backup into the store. Nothing on the phone is deleted; the
/// backup only fills gaps. All changes are saved together, and a failed save is
/// rolled back so nothing is half-restored. Restoring the same file twice changes nothing.
public enum BackupMerger {
    public static func merge(_ backup: OpenedBackup, into context: ModelContext,
                             save: (ModelContext) throws -> Void = { try $0.save() }) throws -> RestoreResult {
        let manifest = backup.manifest
        var result = RestoreResult()
        do {
            var cabinetStyles = Set(try context.fetch(FetchDescriptor<CabinetItem>()).map(\.ingredientStyleId))
            for record in manifest.cabinet where !cabinetStyles.contains(record.ingredientStyleId) {
                context.insert(record.makeModel())
                cabinetStyles.insert(record.ingredientStyleId)
                result.cabinetAdded += 1
            }

            var shoppingStyles = Set(try context.fetch(FetchDescriptor<ShoppingItem>()).map(\.ingredientStyleId))
            for record in manifest.shopping
            where !shoppingStyles.contains(record.ingredientStyleId) && !cabinetStyles.contains(record.ingredientStyleId) {
                context.insert(record.makeModel())
                shoppingStyles.insert(record.ingredientStyleId)
                result.shoppingAdded += 1
            }

            var favouriteRecipes = Set(try context.fetch(FetchDescriptor<FavouriteRecipe>()).map(\.recipeId))
            for record in manifest.favourites where !favouriteRecipes.contains(record.recipeId) {
                context.insert(record.makeModel())
                favouriteRecipes.insert(record.recipeId)
                result.favouritesAdded += 1
            }

            var takesByRecipe = Dictionary(try context.fetch(FetchDescriptor<RecipeTake>()).map { ($0.recipeId, $0) },
                                           uniquingKeysWith: { first, _ in first })
            let recipesWithBackupPhotos = Set(manifest.photos.map(\.recipeId))
            for record in manifest.takes {
                if let existing = takesByRecipe[record.recipeId] {
                    guard record.updatedAt > existing.updatedAt else { continue }
                    existing.rating = record.rating
                    existing.notes = record.notes
                    existing.updatedAt = record.updatedAt
                    if existing.recipeName.isEmpty { existing.recipeName = record.recipeName }
                    result.takesUpdated += 1
                } else {
                    let isEmptyTake = record.rating == 0
                        && record.notes.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty
                        && !recipesWithBackupPhotos.contains(record.recipeId)
                    guard !isEmptyTake else { continue }
                    let take = record.makeModel()
                    context.insert(take)
                    takesByRecipe[record.recipeId] = take
                    result.takesAdded += 1
                }
            }

            var photoDescriptor = FetchDescriptor<RecipePhoto>()
            photoDescriptor.propertiesToFetch = [\.id, \.recipeId]
            let existingPhotos = try context.fetch(photoDescriptor)
            var photoIds = Set(existingPhotos.map(\.id))
            var photoCounts: [UUID: Int] = [:]
            for photo in existingPhotos { photoCounts[photo.recipeId, default: 0] += 1 }
            for record in manifest.photos.sorted(by: { $0.dateAdded < $1.dateAdded }) {
                guard !photoIds.contains(record.id) else { continue }
                guard photoCounts[record.recipeId, default: 0] < TakeLimits.maxPhotos else {
                    result.photosSkippedForLimit += 1
                    continue
                }
                let full = try Data(contentsOf: backup.url(for: record.fullFile))
                let thumbnail = try Data(contentsOf: backup.url(for: record.thumbnailFile))
                context.insert(RecipePhoto(id: record.id, recipeId: record.recipeId, thumbnail: thumbnail, full: full,
                                           dateAdded: record.dateAdded))
                photoIds.insert(record.id)
                photoCounts[record.recipeId, default: 0] += 1
                result.photosAdded += 1
                if takesByRecipe[record.recipeId] == nil {
                    let take = RecipeTake(recipeId: record.recipeId, recipeName: "")
                    context.insert(take)
                    takesByRecipe[record.recipeId] = take
                    result.takesAdded += 1
                }
            }

            guard !result.isEmpty else { return result }
            try save(context)
            AppLog.backup.info("Restored backup: \(result.cabinetAdded) cabinet, \(result.favouritesAdded) favourites, \(result.shoppingAdded) shopping, \(result.takesAdded) takes added, \(result.takesUpdated) updated, \(result.photosAdded) photos")
            return result
        } catch {
            context.rollback()
            let mapped = BackupError.from(error, otherwise: .restoreFailed)
            AppLog.backup.error("Restore failed, rolled back: \(String(describing: mapped), privacy: .public)")
            throw mapped
        }
    }
}
```

```swift
import Observation
import SwiftData

/// App-wide backup state (Backup spec §3–4). Building and opening a file run off
/// the main actor; the merge runs on the main context, which is saved first so
/// pending edits (a note mid-debounce) are included and never rolled back.
@MainActor
@Observable
public final class BackupViewModel {
    public enum State: Equatable {
        case idle
        case preparing
        case ready(URL)
        case reading
        case opened(BackupSummary)
        case restoring
        case finished(RestoreResult)
        case failed(BackupError)
    }

    public private(set) var state: State = .idle

    private let container: ModelContainer
    private let appVersion: String
    private let temporaryDirectory: URL
    private let onRestored: @MainActor () -> Void
    private var opened: OpenedBackup?

    public init(container: ModelContainer, appVersion: String,
                temporaryDirectory: URL = FileManager.default.temporaryDirectory,
                onRestored: @escaping @MainActor () -> Void = {}) {
        self.container = container
        self.appVersion = appVersion
        self.temporaryDirectory = temporaryDirectory
        self.onRestored = onRestored
    }

    public var isBusy: Bool {
        switch state {
        case .preparing, .reading, .restoring: return true
        default: return false
        }
    }

    public func makeBackup() async {
        guard !isBusy else { return }
        reset()
        state = .preparing
        try? container.mainContext.save()
        let container = container, appVersion = appVersion, temporaryDirectory = temporaryDirectory
        do {
            let url = try await Task.detached(priority: .userInitiated) {
                try BackupWriter.write(container: container, appVersion: appVersion, temporaryDirectory: temporaryDirectory)
            }.value
            state = .ready(url)
        } catch {
            state = .failed(BackupError.from(error, otherwise: .exportFailed))
        }
    }

    /// Opens a file from the file picker or from "Open in" (Files, AirDrop).
    public func open(url: URL) async {
        guard !isBusy else { return }
        reset()
        state = .reading
        let temporaryDirectory = temporaryDirectory
        do {
            let backup = try await Task.detached(priority: .userInitiated) {
                try Self.withReadableFile(url) { try BackupReader.open($0, temporaryDirectory: temporaryDirectory) }
            }.value
            opened = backup
            state = .opened(backup.summary)
        } catch {
            state = .failed(BackupError.from(error, otherwise: .notABackup))
        }
    }

    public func confirmRestore() {
        guard case .opened = state, let backup = opened else { return }
        state = .restoring
        try? container.mainContext.save()
        do {
            let result = try BackupMerger.merge(backup, into: container.mainContext)
            closeOpened()
            state = .finished(result)
            onRestored()
        } catch {
            closeOpened()
            state = .failed(BackupError.from(error, otherwise: .restoreFailed))
        }
    }

    /// Dismisses whatever is showing and removes temporary files. Ignored while busy.
    public func cancel() {
        guard !isBusy else { return }
        reset()
        state = .idle
    }

    private func reset() {
        closeOpened()
        if case .ready(let url) = state {
            try? FileManager.default.removeItem(at: url.deletingLastPathComponent())
        }
    }

    private func closeOpened() {
        opened?.close()
        opened = nil
    }

    /// Security-scoped, coordinated access, so files in iCloud Drive are downloaded before reading.
    nonisolated static func withReadableFile<T>(_ url: URL, _ body: (URL) throws -> T) throws -> T {
        let isScoped = url.startAccessingSecurityScopedResource()
        defer { if isScoped { url.stopAccessingSecurityScopedResource() } }
        var coordinationError: NSError?
        var result: Result<T, Error>?
        NSFileCoordinator().coordinate(readingItemAt: url, options: [.withoutChanges], error: &coordinationError) { readableURL in
            result = Result { try body(readableURL) }
        }
        if let coordinationError { throw BackupError.from(coordinationError, otherwise: .notABackup) }
        guard let result else { throw BackupError.notABackup }
        return try result.get()
    }
}
```

```swift
import SwiftUI
import NorseMixologyCore

/// Presents the backup share sheet, restore summary and errors from the app root,
/// so a `.nmbackup` opened from Files or AirDrop shows its summary on any tab.
struct BackupPresenter: ViewModifier {
    @Environment(BackupViewModel.self) private var backup

    func body(content: Content) -> some View {
        content
            .sheet(isPresented: isSharing) {
                if case .ready(let url) = backup.state {
                    ActivityView(items: [url]) { backup.cancel() }
                        .presentationDetents([.medium, .large])
                }
            }
            .sheet(isPresented: isRestoring) {
                RestoreSummarySheet()
            }
            .alert("Backup", isPresented: isFailed) {
                Button("OK") { backup.cancel() }
            } message: {
                Text(failureMessage)
            }
            .onOpenURL { url in
                guard url.pathExtension.lowercased() == "nmbackup" else { return }
                Task { await backup.open(url: url) }
            }
    }

    private var isSharing: Binding<Bool> {
        Binding(
            get: { if case .ready = backup.state { return true } else { return false } },
            set: { if !$0 { backup.cancel() } }
        )
    }

    private var isRestoring: Binding<Bool> {
        Binding(
            get: {
                switch backup.state {
                case .opened, .restoring, .finished: return true
                default: return false
                }
            },
            set: { if !$0 { backup.cancel() } }
        )
    }

    private var isFailed: Binding<Bool> {
        Binding(
            get: { if case .failed = backup.state { return true } else { return false } },
            set: { if !$0 { backup.cancel() } }
        )
    }

    private var failureMessage: LocalizedStringKey {
        guard case .failed(let error) = backup.state else { return "Something went wrong." }
        switch error {
        case .notABackup: return "This file isn't a Norse Mixology backup."
        case .newerVersion: return "This backup was made by a newer version of the app. Update the app to restore it."
        case .damaged: return "This backup is damaged and can't be restored."
        case .outOfSpace: return "There isn't enough free space. Free some space and try again."
        case .exportFailed: return "Couldn't create the backup. Try again."
        case .restoreFailed: return "Couldn't restore. Nothing was changed."
        }
    }
}

extension View {
    func backupPresenter() -> some View {
        modifier(BackupPresenter())
    }
}
```
